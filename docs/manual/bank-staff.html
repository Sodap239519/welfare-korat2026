🎯 งานหลักของ Bank Staff — Flow ปกติ

Step 1: เปิดหน้า "ห่อเอกสารธนาคาร"

  • Login เสร็จ ระบบจะพาคุณมาที่ tab "รอดำเนินการ" อัตโนมัติ
  • เห็นเฉพาะ batch ของธนาคารของคุณเท่านั้น (ระบบกรองให้แล้ว)

Step 2: เมื่อ Tracker มาส่งเอกสารที่สาขา

  1. ตรวจ เลขที่ batch (เช่น #2026-05-29-001) บนหน้าเอกสารที่ tracker เอามา
  2. ค้นหาในระบบ → คลิกการ์ดที่ตรงกัน
  3. ดูรายชื่อใน batch → นับเอกสารจริง ตรงกันไหม
  4. ถ้าครบ → กดปุ่ม ✅ ยืนยันรับเอกสาร (สีฟ้า)

Step 3: เมื่อบันทึกข้อมูลลง core ของธนาคารครบทุกราย

  1. กลับมาที่ batch เดิม (ตอนนี้สถานะ "ธ.รับแล้ว")
  2. กดปุ่ม 💾 ยืนยันบันทึกครบ (สีเขียว)
  3. ระบบส่ง LINE แจ้ง tracker: "บันทึกครบแล้ว"
  4. จบงานของคุณ — batch จะเป็น "บันทึกครบ"

⛔ ปฏิเสธ batch (กรณีเอกสารผิด)

เมื่อไหร่ที่ใช้

  • เอกสารไม่ครบ (เช่น ขาดสำเนาบัตร ปชช.)
  • ข้อมูลในเอกสารผิด (เลขประจำตัวไม่ตรง)
  • เอกสารหมดอายุ / ไม่อ่านชัด
  • มีรายชื่อที่ไม่เกี่ยวข้อง

ขั้นตอน

  1. คลิก batch ที่มีปัญหา
  2. กดปุ่ม ⛔ ปฏิเสธ (สีแดง)
  3. กรอก เหตุผล (≥ 5 ตัวอักษร) ให้ชัดเจน เช่น:
    • "ขาดสำเนาบัตร ปชช. 3 ราย"
    • "ลายเซ็นไม่ครบใน 5 ฉบับ"
  4. กด ยืนยันปฏิเสธ

ผลที่ตามมา

  • batch → สถานะ "ปฏิเสธ"
  • รายชื่อในนั้นกลับสถานะเดิม (sub_status_code = null)
  • LINE แจ้ง tracker พร้อมเหตุผล
  • Tracker จะแก้แล้วส่ง batch ใหม่มา

KPI 5 ใบ

ตัวเลข ความหมาย
📤 ส่งวันนี้ tracker ส่งเข้ามาวันนี้กี่ห่อ
⏳ รอ ธ.รับ คุณยังไม่กดรับกี่ห่อ (ต้องรีบ!)
📥 รอบันทึก คุณรับแล้วแต่ยังไม่บันทึกครบ
✅ บันทึก บันทึกครบวันนี้กี่ห่อ
⛔ ปฏิเสธ ปฏิเสธวันนี้กี่ห่อ

คอขวด > 3 วัน

  • batch ของธนาคารคุณที่ค้างนานเกิน 3 วัน
  • ควรเร่งดำเนินการเพื่อไม่ให้ tracker รอนาน

🔔 LINE Notifications

คุณจะไม่ได้รับ notification ทาง LINE โดยตรง — เพราะคุณดูที่ระบบเป็นหลัก

แต่ถ้า Super Admin เพิ่มคุณเข้ากลุ่ม LINE Admin ก็จะเห็น event ทั้งหมด

❓ Tips

🎯 รับ batch ครั้งละหลายๆ ห่อ

  • ถ้า tracker หลายคนมาส่งวันเดียวกัน → กดรับทีละ batch
  • ไม่จำเป็นต้องกดทันที — ปุ่มอยู่ตลอด

📋 ใช้ที่อยู่ดูเร็ว

  • คลิกชื่อในรายการ batch → ไปดู TargetDetail
  • เห็นที่อยู่หมู่บ้าน + ตำบล + อำเภอ ครบ

🕐 บันทึกครบใน 1-2 วัน

  • ระบบนับ "ธนาคารเร็วสุด" จากเวลาส่ง→บันทึก
  • ทำเร็ว = ขึ้น TOP ใน Dashboard ผู้บริหาร

🆘 Troubleshooting

ปัญหา วิธีแก้
ไม่เห็น batch ใหม่ กดรีเฟรชหน้า (F5) — หรือสลับ tab แล้วกลับมา
รับ batch ผิด (ยังไม่ตรง) บอก tracker ให้แก้ไข + แจ้ง Super Admin ใน chat
ลืมว่าใครอยู่ใน batch คลิก batch → เห็นรายชื่อครบ
รหัสผ่านหาย ติดต่อ Super Admin ของระบบ
เห็น batch ของธนาคารอื่น (ไม่ควรเห็น) แจ้ง Super Admin — อาจเป็น bug
