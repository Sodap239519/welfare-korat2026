# 🏘️ คู่มือ Tracker (ผู้กำกับติดตาม)

สำหรับ **กำนัน / ผู้ใหญ่บ้าน / อสม. / อปท. / กรรมการหมู่บ้าน** ที่ติดตามการลงทะเบียนบัตรสวัสดิการในพื้นที่ของตน

## สิ่งที่คุณทำได้

- ดูรายชื่อกลุ่มเป้าหมาย**ในหมู่บ้านที่คุณดูแล** (filter อัตโนมัติ)
- อัปเดตสถานะลงทะเบียนของแต่ละคน
- **ส่งห่อเอกสารให้ธนาคาร** (ฟีเจอร์หลัก!) — รวมหลายคนเป็น batch
- ติดตาม batch ของตัวเอง (ธนาคารรับ/บันทึก/ปฏิเสธ)
- ดูแผนที่หมู่บ้าน
- ดู Dashboard เฉพาะพื้นที่ตน

## สิ่งที่คุณทำไม่ได้

- ❌ ดูข้อมูลหมู่บ้านที่ไม่ใช่ของคุณ
- ❌ จัดการบัญชีผู้ใช้
- ❌ ตั้งค่าระบบ
- ❌ นำเข้าข้อมูล Excel
- ❌ รับ/บันทึก batch (เป็นหน้าที่ของธนาคาร)

## 📝 สมัครสมาชิก (ครั้งแรก)

1. เข้าเว็บไซต์ → กดลิงก์ **"สมัครสมาชิก"** ที่หน้า Login
2. กรอกข้อมูล:
   - **ชื่อ-สกุล** (เต็ม)
   - **เบอร์โทร** (จะใช้เป็น username)
   - **รหัสผ่าน** (≥ 6 ตัว)
   - **ตำแหน่ง**: กำนัน / ผู้ใหญ่บ้าน / ผู้ช่วยฯ / อสม. / ส.อบต. / อื่นๆ
   - **อำเภอ → ตำบล → ชื่อหมู่บ้าน** (เลือก cascade)
3. กด **สมัคร**
4. รอ Super Admin อนุมัติ (จะได้รับแจ้ง LINE หรือเปิดระบบลองดู)
5. หลังอนุมัติแล้ว → login ได้

> 💡 **ชื่อหมู่บ้าน** จะครอบทุกหมู่ที่ของหมู่บ้านนั้น เช่น เลือก "บ้านดอนใหญ่" จะดูแลทุก ม. ของบ้านดอนใหญ่

## 🎯 งานหลักของ Tracker — Flow ปกติ

### Step 1: ดูว่ามีใครยังต้องติดตาม
1. ไป 📊 **Dashboard** → ดู KPI ใบสีสันต่างๆ
2. คลิกการ์ด **"ยังไม่ถูกติดตาม"** (สีเทา)
3. ระบบพาไปหน้า 👥 รายชื่อเป้าหมาย พร้อม filter

### Step 2: อัปเดตสถานะรายคน (วิธีง่ายสุด)
1. คลิกชื่อ → หน้า TargetDetail
2. ดูประวัติสถานะที่ผ่านมา
3. กดปุ่ม **อัปเดตสถานะ**
4. เลือก:
   - **สถานะใหม่** เช่น "อยู่ระหว่างการลงทะเบียน"
   - **ช่องทาง** เช่น ผ่านธนาคาร / ตนเอง / อปท.
   - **หมายเหตุ** ถ้าจำเป็น
5. กด **บันทึก**

## 📦 ฟีเจอร์หลัก: ส่งห่อเอกสารให้ธนาคาร

### เมื่อไหร่ที่ใช้
- คุณช่วยรวบรวมเอกสารของชาวบ้านหลายคน
- ต้องเอาไปที่สาขาธนาคารวันเดียวกัน
- **อยากให้ระบบจำว่าใครส่งไปที่ไหนแล้ว** ไม่ลืม + ติดตามได้

### ขั้นตอน (3 คลิก)

#### 1️⃣ เลือกหลายคนพร้อมกัน
- ไป 👥 **รายชื่อเป้าหมาย**
- Filter หาคนที่ "อยู่ระหว่างการลงทะเบียน" หรือ "ยังไม่ถูกติดตาม"
- ติ๊กกล่อง ☑️ ทีละคน (หรือกดกล่องบนสุดเพื่อเลือกทั้งหน้า)

#### 2️⃣ กดปุ่ม "📦 ใส่ห่อเอกสาร" (สีเหลือง)
จะเห็น floating bar ด้านล่างขึ้น 2 ปุ่ม:
- 📦 ใส่ห่อเอกสาร ← กดอันนี้
- ✏️ อัปเดตสถานะ (กรณีไม่ส่งให้ธนาคาร)

#### 3️⃣ กรอก modal สีเหลือง
- **วันที่ส่ง**: วันที่คุณจะเอาไปธนาคาร (default = วันนี้)
- **ส่งให้**: เลือก "ธนาคาร 5 แห่ง" (default)
- **ธนาคาร**: เลือก KTB / GSB / BAAC / GHB / IBANK
- **ใครเป็นคนส่ง**: กดเลือก กำนัน / ผู้ใหญ่บ้าน / อสม. / อปท. / อื่นๆ
  - ถ้าเลือก "อื่นๆ" → กรอกชื่อด้วย
- **หมายเหตุ**: เช่น "เอกสารแนบ 2 แผ่น/คน"
- กด **สร้าง batch + เพิ่ม X ราย**

#### 4️⃣ Review + ส่งให้ธนาคาร
ระบบจะพาไปที่หน้า **BatchDetail** อัตโนมัติ:
- ตรวจสอบรายชื่อให้ครบ
- ถ้ามีคนที่ไม่ต้องส่ง → กด ❌ ออกจาก batch
- ถ้าครบแล้ว → กดปุ่ม **🚀 ส่งให้ธนาคาร** (สีเหลือง)
- ระบบส่ง LINE แจ้งธนาคาร + เปลี่ยนสถานะทุกคนเป็น "ส่งแบบฟอร์มแล้ว" (4.2.2)

## 📋 ติดตาม batch ที่ส่งไปแล้ว

ไป 📦 **ห่อเอกสารธนาคาร** → tab **"ของฉัน"**:

### Status ของ batch จะเปลี่ยนทีละขั้น
| สถานะ | ความหมาย | ใครต้องทำ |
|---|---|---|
| 📄 **ร่าง** | ยังไม่ได้ส่ง | คุณ (กดส่ง) |
| 📤 **ส่งแล้ว** | รอธนาคารรับ | ธนาคาร |
| 📥 **ธ.รับแล้ว** | ธนาคารกำลังบันทึก | ธนาคาร |
| ✅ **บันทึกครบ** | จบกระบวนการ ✨ | (อัตโนมัติ) |
| ⛔ **ปฏิเสธ** | ธนาคารปฏิเสธ + ระบุเหตุผล | คุณ (แก้ + ส่งใหม่) |

### Notifications ที่จะได้รับ
🔔 ระฆัง + (LINE ถ้าตั้งไว้)
- ✅ "ธ.XXX รับ batch #001 ของคุณแล้ว"
- 🎉 "บันทึก batch #001 ครบ N ราย"
- ⛔ "batch #001 ถูกปฏิเสธ: [เหตุผล]"

## 🆘 ถ้าธนาคารปฏิเสธ batch

1. คลิก notification หรือไปที่ batch ที่ถูกปฏิเสธ
2. อ่านกล่องสีแดง "เหตุผลที่ปฏิเสธ"
3. แก้ปัญหาตามที่ระบุ (เช่น ขอเอกสารเพิ่ม)
4. **รายชื่อทั้งหมดในนั้นจะกลับสถานะเดิม** อัตโนมัติ
5. สร้าง batch ใหม่ → ส่งอีกครั้ง

## ❓ Tips สำหรับ Tracker

### 🎯 รวมงานเป็นครั้งๆ ดีกว่าทีละคน
- ถ้าคุณรู้ว่าจะไปธนาคารวันพุธ → รวมเอกสารของทุกคนใส่ batch เดียว
- ระบบจะบันทึกว่า "วันนี้ส่งกี่คน" ให้อัตโนมัติ
- LINE แจ้งธนาคารครั้งเดียว ลดความรำคาญ

### 📱 ใช้บนมือถือ
- ทุกหน้าออกแบบให้ใช้บนมือถือดี
- ปุ่ม "📦 ใส่ห่อเอกสาร" อยู่บน floating bar กดง่ายด้วยนิ้วโป้ง
- Modal เต็มจอ — กรอกง่าย

### 🔔 เปิด LINE notification
- ขอเชิญ admin เข้ากลุ่ม LINE ตัวคุณ → จะได้รับแจ้งเตือนทันที
- หรือเช็ค 🔔 ระฆังบ่อยๆ

## 🆘 Troubleshooting

| ปัญหา | วิธีแก้ |
|---|---|
| ส่ง batch แล้วธนาคารไม่รับนาน | โทรหา/ไปหาธนาคารโดยตรง — ระบบไม่บังคับเร่งให้ |
| ลืมว่าใครอยู่ใน batch | ไป 📦 → tab ของฉัน → คลิก batch → ดูรายชื่อ |
| ระบบไม่เห็นชาวบ้านบางคน | ตรวจว่าเขาอยู่ในหมู่บ้านที่คุณดูแลไหม — ถ้าไม่ → แจ้ง Super Admin |
| ไม่ได้รับ notification | กดที่ 🔔 ตรวจ + ตั้ง browser ให้แสดง notification |
| password หาย | ติดต่อ Super Admin (ไม่มี self-reset) |
