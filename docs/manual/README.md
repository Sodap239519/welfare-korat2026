## 🔐 ขั้นตอน Login ทั่วไป

1. เข้าเว็บไซต์ที่ admin มหาวิทยาลัยให้
2. กรอก **เบอร์โทรศัพท์** (เป็น username)
3. กรอก **รหัสผ่าน** (ขั้นต่ำ 6 ตัว)
4. กด "เข้าสู่ระบบ"

> 💡 **ลืมรหัสผ่าน?** ติดต่อ Super Admin ของระบบให้ reset ให้

## 🎨 องค์ประกอบ UI หลัก

### Topbar (แถบบนสุด)
- ☀️/🌙 ปุ่มสลับธีม สว่าง/มืด
- A- / 16pt / A+ ปรับขนาดตัวอักษร
- 🔔 ระฆังแจ้งเตือน (มีเลขเด้งเมื่อมี notification ใหม่)
- 👤 รูปโปรไฟล์ → แก้ไขข้อมูลส่วนตัว, ออกจากระบบ

### Sidebar (แถบเมนูซ้าย)
- เห็นเมนูต่างกันตาม role
- บนมือถือ → กดไอคอน ☰ มุมบนซ้ายเพื่อเปิด

### Bottom Navigation (เฉพาะมือถือ)
- 4 ปุ่มไอคอนหลัก ติดล่างจอ — เข้าถึงด่วน

## ❓ คำถามที่พบบ่อย

**Q: เปิดบนมือถือได้ไหม?**
A: ได้ทุกอย่าง — ดู Dashboard, แก้สถานะ, ส่งห่อเอกสาร ทำได้บนมือถือเหมือน desktop

**Q: ใช้ offline ได้ไหม?**
A: ❌ ต้องมี internet — ระบบ sync สดทุกครั้ง

**Q: ข้อมูลปลอดภัยไหม?**
A: ✅ HTTPS + bcrypt password + Spatie role permission + audit log ทุก action

**Q: ติดปัญหาแจ้งใคร?**
A: แจ้ง Super Admin ที่ดูแลระบบ (admin มหาวิทยาลัย NRRU)
