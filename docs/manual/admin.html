📊 หน้า Dashboard — อ่านอย่างไร

ส่วนบน — KPI สถานะ

  • การ์ดสีต่างๆ แสดงจำนวนคนในแต่ละสถานะ (4.1-4.7 + ยังไม่ติดตาม)
  • คลิกการ์ดไปที่หน้า Targets แบบ filter ทันที

SOP 5 ขั้น

  • เห็นว่าโครงการอยู่ในขั้นไหน (ขั้นปัจจุบันมีกรอบสีน้ำเงิน)
  • ขั้นที่ผ่านไปแล้วเป็นสีเขียว ขั้นต่อไปสีเทา

📦 Document Batch (ฟีเจอร์ใหม่)

  • KPI 5 ใบ: ส่งวันนี้/รอ ธ.รับ/รอบันทึก/บันทึกวันนี้/ปฏิเสธ
  • คอขวด > 3 วัน: batch ที่ค้างนานเกินไป (ควรเตือน tracker หรือธนาคาร)
  • ธนาคารเร็วสุด TOP 5: เฉลี่ยกี่วันจากส่ง → บันทึกเสร็จ
  • Tracker ขยันสุด TOP 5: ใครส่งห่อมากสุดใน 7 วัน

กราฟแนวโน้ม

  • เลือกช่วงเวลา (7/14/30/60 วัน) หรือกำหนดเอง
  • ดู % ความคืบหน้าและจำนวนสะสม

👥 การจัดการรายชื่อเป้าหมาย

ค้นหา + Filter

  1. กล่องค้นหา: พิมพ์ชื่อ/นามสกุล/เลขบัตร
  2. ดรอปดาวน์: อำเภอ → ตำบล → หมู่บ้าน (cascade)
  3. Filter สถานะ: คลิก pill สี (4.1-4.7 + ยังไม่ติดตาม)

อัปเดตสถานะรายคน

  • คลิกชื่อ → หน้า TargetDetail
  • ดูประวัติสถานะทั้งหมด (timeline)
  • กดปุ่ม "อัปเดตสถานะ" → เลือกสถานะ + ช่องทาง + หมายเหตุ

อัปเดต Bulk (หลายคนพร้อมกัน)

  1. ติ๊กกล่อง ☑️ หน้าชื่อ (เลือกหลายคน)
  2. Floating bar ด้านล่างจะโผล่ขึ้น
  3. กดปุ่ม ✏️ อัปเดตสถานะ → modal เปิด
  4. เลือกสถานะใหม่ + ช่องทาง + หมายเหตุ (ถ้าจำเป็น)
  5. กด ยืนยัน → อัปเดตทุกคนพร้อมกัน (สูงสุด 500/ครั้ง)

📦 จัดการ Document Batch

เห็นอะไรบ้าง

  • Tab "รอดำเนินการ": batch ที่ submitted หรือ received ทุกธนาคาร
  • Tab "ของฉัน": batch ที่ admin สร้างเอง
  • Tab "ทั้งหมด": ทุก batch ทุกสถานะ

สร้าง batch ส่งธนาคาร (เหมือน tracker)

  1. ไปหน้า 👥 รายชื่อเป้าหมาย
  2. Filter หาคนที่ต้องส่งให้ธนาคารดำเนินการ
  3. ติ๊ก ☑️ เลือก 5-100 คน
  4. กดปุ่ม 📦 ใส่ห่อเอกสาร (สีเหลือง)
  5. เลือก:
    • วันที่ส่ง
    • ธนาคารปลายทาง (KTB/GSB/BAAC/GHB/IBANK)
    • ตำแหน่งผู้ส่ง (กำนัน/ผู้ใหญ่บ้าน/อสม./อปท./อื่นๆ)
  6. กดสร้าง → ไปที่ BatchDetail → กด ส่งให้ธนาคาร

รับ/บันทึก batch แทน bank_staff

ในกรณีที่ admin ต้องการช่วยธนาคาร:

  1. ไป 📦 ห่อเอกสาร → tab รอดำเนินการ
  2. คลิก batch → BatchDetail
  3. กดปุ่ม:
    • ✅ ยืนยันรับเอกสาร (สีฟ้า) — submitted → received
    • 💾 ยืนยันบันทึกครบ (สีเขียว) — received → recorded
    • ⛔ ปฏิเสธ (สีแดง) + ระบุเหตุผล

⚠️ ระวัง: Admin ทำได้ทุกธนาคาร ใช้สิทธิ์นี้เฉพาะกรณีจำเป็น (ปกติให้ bank_staff ทำเอง)

📈 ดูรายงาน + Export

ไปที่ 📈 รายงาน → เลือก tab:

  1. สรุปยอด — ตารางสถานะแต่ละอำเภอ/ตำบล/หมู่บ้าน
  2. รายชื่อต้นฉบับ — list กลุ่มเป้าหมายดิบ
  3. รายชื่อ+สถานะ — รวมสถานะปัจจุบัน
  4. รายชื่อผู้ติดตาม — ใครดูแลใคร

ทุก tab กด Export Excel ได้

🔔 LINE Notifications

Admin จะรับ notification เหมือน super_admin ครบทุก event:

  • ผู้ใช้สมัครใหม่
  • Batch lifecycle (submitted/received/recorded/rejected)
  • Daily snapshot
  • 3-day report

🆘 Troubleshooting

ปัญหา วิธีแก้
อัปเดตสถานะแล้วไม่ขึ้น ตรวจสอบ flash message สีเขียวด้านบน + รีเฟรชหน้า
Bulk update เกิน 500 ราย แบ่งทำ 2-3 รอบ (ระบบจำกัดที่ 500/ครั้ง)
คลิก batch แล้ว 403 คุณไม่ใช่เจ้าของ — Admin มีสิทธิ์ดูทุก batch แต่ถ้า error → relogin
ปฏิเสธ batch แล้ว tracker ไม่รู้ ตรวจ LINE bot อยู่ในกลุ่ม + tracker เห็นใน 🔔 ระฆัง
