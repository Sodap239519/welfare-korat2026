# 🛡️ คู่มือ Super Admin

ผู้ดูแลระบบสูงสุด — รับผิดชอบตั้งค่าระบบ + จัดการบัญชีผู้ใช้ + นำเข้าข้อมูล

## สิ่งที่ Super Admin ทำได้ (สิทธิ์เต็ม 100%)

- จัดการบัญชีผู้ใช้ทั้งหมด (เพิ่ม/แก้/ลบ/อนุมัติ/พักงาน)
- ตั้งค่าระบบ (สถานะลงทะเบียน, ช่องทาง, ธนาคาร, ขั้นตอน SOP)
- นำเข้ารายชื่อกลุ่มเป้าหมายจาก Excel
- ดู/แก้ข้อมูลทุกระดับ (อำเภอ/ตำบล/หมู่บ้าน)
- ดู Activity Log (ใครทำอะไรเมื่อไหร่)
- แก้พิกัดหมู่บ้านบนแผนที่
- รับ LINE notification ทุกเหตุการณ์

## 📋 งานที่ต้องทำตอนเริ่มระบบ (ครั้งแรก)

### Step 1: ตั้งค่าระบบพื้นฐาน
**ไปที่ ⚙️ ตั้งค่าข้อมูล** → ตรวจสอบ 4 tab:
1. **ช่องทางลงทะเบียน** — มีช่องทางครบหรือยัง (ผ่านธนาคาร, ลงตนเอง, ผ่านอำเภอ...)
2. **สถานะลงทะเบียน** — 4.1-4.7 ครบหรือไม่ ปรับชื่อตามที่หน่วยงานใช้
3. **ธนาคาร** — 5 ธนาคาร (KTB/GSB/BAAC/GHB/IBANK) พร้อมโลโก้
4. **ขั้นตอน SOP** — 5 ขั้นของกระบวนการ ตั้ง "ขั้นปัจจุบัน" ว่าตอนนี้อยู่ขั้นไหน

### Step 2: นำเข้ารายชื่อกลุ่มเป้าหมาย
**ไปที่ 📥 นำเข้าข้อมูล**:
1. กดเลือกไฟล์ Excel (.xlsx)
2. กด **Preview** ดูว่าข้อมูลถูกต้องไหม
3. กด **Run Import** เพื่อนำเข้าจริง
4. ระบบจะตรวจ duplicate + บันทึก log

> 💡 **กับดักวันที่ Excel**: บ้านเลขที่ "27/1" Excel แปลงเป็น "27-ม.ค." อัตโนมัติ → ต้องแก้ใน Excel ก่อน upload

### Step 3: สร้างบัญชีให้ทีมงาน
**ไปที่ 👤 จัดการผู้ใช้** → กด **+ เพิ่มผู้ใช้**:

#### สร้าง Admin (ผู้ดูแลระดับอำเภอ)
- Role: **Admin**
- ใส่ชื่อ-นามสกุล + เบอร์โทร + password
- ไม่ต้องผูก scope

#### สร้าง Bank Staff (เจ้าหน้าที่ธนาคาร)
- Role: **เจ้าหน้าที่ธนาคาร**
- กล่องส้ม "ขอบเขตธนาคาร" จะโผล่ขึ้น → เลือก:
  - ช่องทาง: ธนาคาร 5 แห่ง
  - ธนาคารย่อย: KTB / GSB / BAAC / GHB / IBANK
- บัญชีจะเห็นแค่ batch ของธนาคารที่กำหนด

#### Tracker — สมัครเองได้
ไม่ต้องสร้าง — แจ้งให้กำนัน/ผู้ใหญ่บ้าน/อสม./อปท. ไปที่หน้า **สมัครสมาชิก** เอง → ระบบจะรอ Super Admin อนุมัติ

## 🔔 อนุมัติ Tracker ใหม่

เมื่อมี tracker สมัครใหม่:
1. 🔔 ระฆังจะเด้ง + LINE แจ้งเตือน "มีผู้ใช้รออนุมัติ"
2. ไปที่ 👤 **จัดการผู้ใช้** → filter Role = "ผู้กำกับติดตาม" + Status = "รออนุมัติ"
3. ตรวจชื่อ + เบอร์ + หมู่บ้านที่เลือก
4. กดปุ่ม **✅ อนุมัติ** หรือ **❌ พักงาน**

## ⚙️ การจัดการสถานะลงทะเบียน

**ตั้งค่าข้อมูล → tab สถานะลงทะเบียน**

- **เพิ่มสถานะใหม่**: กด "+ เพิ่มสถานะ" → กรอก code (เช่น 4.8) + ชื่อ + สี
- **แก้ไขชื่อ**: กดไอคอน ✏️ → แก้แล้ว save → **ทุกหน้าเปลี่ยนทันที** (dynamic)
- **ลบสถานะ**: กดไอคอน 🗑️ (ระวัง — ถ้ามี target ใช้อยู่จะลบไม่ได้)

> 🎯 **Tip**: สี pill ของ code 4.x ใช้ class CSS `st-4-X` (เช่น `st-4-1`, `st-4-7`)

## 📈 ดู Reports + Export

**ไปที่ 📈 รายงาน**:
- 4 tab: สรุปยอด / รายชื่อต้นฉบับ / รายชื่อ+สถานะ / รายชื่อผู้ติดตาม
- Filter: ระดับ (อำเภอ/ตำบล/หมู่บ้าน) + วันที่
- Pagination 35 รายการ/หน้า
- กดปุ่ม **Export Excel** ดาวน์โหลด

## 🗺️ แก้พิกัดหมู่บ้าน

**ไปที่ 🗺️ แผนที่หมู่บ้าน**:
- คลิกหมุดสีน้ำเงิน → ดูข้อมูลหมู่บ้าน
- **ลากหมุดได้** (เฉพาะ Super Admin) → save อัตโนมัติ
- กดปุ่ม 🔍 ใส่ที่อยู่ → Geocode อัตโนมัติผ่าน OSM
- กด ⏪ Undo ถ้าลากผิด

## 🔄 LINE Notifications ที่ Super Admin จะได้รับ

ส่งเข้ากลุ่ม LINE Admin:
- 👤 ผู้ใช้สมัครใหม่ → รออนุมัติ
- 📦 Tracker ส่ง batch → ธนาคารต้องรับ
- ✅ ธนาคารรับ batch
- 🎉 ธนาคารบันทึก batch ครบ
- ⛔ ธนาคารปฏิเสธ batch + เหตุผล
- 📊 Report ราย 3 วัน (TOP 5 อำเภอ + ตำบลย่อย)

ส่งเข้ากลุ่ม LINE Report:
- 📅 Daily snapshot (ทุกวัน 16:30)
- 📉 Weekly bottleneck (ทุกจันทร์ 06:00)

## 🆘 Troubleshooting

| ปัญหา | วิธีแก้ |
|---|---|
| user สมัครแล้วไม่เห็นในระบบ | ตรวจ filter — อาจถูกซ่อนเพราะ status pending |
| Excel import พัง | ตรวจคอลัมน์: ต้องตรงกับ template (เลขประจำตัวประชาชน, ชื่อ, สกุล, อำเภอ, ตำบล, หมู่บ้าน, หมู่ที่) |
| สถานะแก้แล้วไม่อัปเดต | กด Ctrl+F5 ล้าง browser cache |
| LINE ไม่แจ้งเตือน | ตรวจ .env: `LINE_MESSAGING_TOKEN` + `LINE_ADMIN_TARGET_ID` ครบ + bot อยู่ในกลุ่ม |
| ลบ tracker ไม่ได้ | tracker อาจมี batch ค้างอยู่ — ปิด batch ก่อน |
