วิธีใส่โลโก้ธนาคาร
====================

วางไฟล์ PNG (พื้นหลังโปร่ง · ขนาด 128x128 หรือใหญ่กว่า) ในโฟลเดอร์นี้
โดยตั้งชื่อเป็น code ของธนาคาร (lowercase):

  - ktb.png    ← ธนาคารกรุงไทย
  - gsb.png    ← ธนาคารออมสิน
  - baac.png   ← ธ.ก.ส.
  - ghb.png    ← ธอส. (ธนาคารอาคารสงเคราะห์)
  - ibank.png  ← ธนาคารอิสลามแห่งประเทศไทย

ระบบจะใช้รูปเหล่านี้แสดงในการ์ด "เจาะลึกช่องทางธนาคาร · 5 แห่ง"
หากไฟล์ไม่มี ระบบจะ fallback เป็น badge ตัวอักษรย่อสี brand อัตโนมัติ
